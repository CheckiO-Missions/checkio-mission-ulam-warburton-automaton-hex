Diese Mission ist der hexagonalen Version der Ulam–Warburton cellular automaton (UWCA) gewidmet - ein 2-dimensionales fraktales Muster, das auf einem regelmäßigen Gitter aus Zellen wächst, die aus Sechsecken bestehen.

Starting with one hexagon initially ON and all others OFF, successive iterations are generated by turning ON all hexagons that share precisely one edge with an ON hexagon.
